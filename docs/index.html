ARCH.JS / DOCUMENTATION

Documentation

ARCH.js is a browser-side runtime and package loader. It provides a simple project structure, loads runtime modules, and lets browser projects use packages through importPackage().

Quick start

Load the current ARCH.js build from your HTML page.

<script src="https://chibbit-99.github.io/arch.js/releases/latest.js"></script>

ARCH.js looks for ./arch/config.json relative to the page.

my-project/
├── index.html
├── arch/
│   ├── config.json
│   └── init.js
└── src/
    └── main.js
A project does not need a package.json just to use ARCH.js. Project startup is described by arch/config.json.

Project layout

index.html is the web page. arch/ contains ARCH.js configuration and optional initialization. src/ contains the application itself.

index.html       page loaded by the browser
arch/
  config.json    runtime modules + project files
  init.js        optional async initialization
src/
  main.js        application entry point

config.json

The configuration selects runtime modules and the JavaScript files ARCH.js should execute.

{
  "modules": ["npmloader.js"],
  "js": ["./src/main.js"]
}

modules

The modules array selects runtime modules. The current repository includes npmloader.js, which provides the browser-side NPM package loader.

js

The js field can be one file or an array of files.

// One file
{
  "modules": ["npmloader.js"],
  "js": "./src/main.js"
}

// Several files
{
  "modules": ["npmloader.js"],
  "js": [
    "./src/components.js",
    "./src/main.js"
  ]
}

arch/init.js

arch/init.js is optional. When present, ARCH.js runs it before the project files and waits for it to finish.

const THREE = await importPackage("three");

globalThis.THREE = THREE;

This is useful for dependency setup or other initialization that should happen before the application starts. Because initialization is asynchronous, await can be used directly.

Project files

Files listed in js are regular browser JavaScript.

// src/main.js

console.log("ARCH.js is running");

document.body.insertAdjacentHTML(
    "beforeend",
    "<p>Hello from ARCH.js.</p>"
);

When multiple files are configured, ARCH.js fetches them concurrently and executes them in the order specified by js.

NPM packages

With npmloader.js enabled, packages can be loaded from project code or from arch/init.js.

const THREE = await importPackage("three");

const scene = new THREE.Scene();
console.log(scene);

The loader resolves the package, prepares it for browser use, handles its package files and dependencies, and returns a module namespace.

Versioned requests and package subpaths can also be used:

const three = await importPackage("three@0.180.0");
const helpers = await importPackage("some-package/helpers");
const exact = await importPackage("some-package@1.2.3/helpers");

API

await importPackage(specifier)
Loads a package and returns its module namespace. Loaded packages can be reused from the cache.
importGlobal(package, export, alias)
Places an export from an already imported package on globalThis. The alias is optional.
await importPackage("three");
importGlobal("three", "Vector3");
importGlobal("three", "ArrowHelper", "Arrow");

importGlobal() does not load a package. The package must already have been imported.

Releases

Browser-ready builds live in releases/.

releases/
├── latest.js
├── v0.1.0-alpha.js
└── v0.1.1-alpha.js

latest.js is the current development build and may change. A versioned file is fixed to a particular release.

<!-- latest -->
<script src="https://chibbit-99.github.io/arch.js/releases/latest.js"></script>

<!-- pinned to v0.1.1-alpha -->
<script src="https://chibbit-99.github.io/arch.js/releases/v0.1.1-alpha.js"></script>

Versioned release files are generated from release tags. Use latest.js while following development, or pin a version when reproducibility matters.

Current release: v0.1.1-alpha. ARCH.js is experimental software, so APIs and architecture may change between releases.

Debugging

Open the browser developer console to see runtime and package-loader messages. ARCH.js messages use the [ARCH] prefix.

const three = await importPackage("three");
console.log(three);
console.log(ARCH);

The global ARCH object can be inspected while debugging. Package loads may also report cache hits in the console.
