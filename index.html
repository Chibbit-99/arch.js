Bring more of JavaScript to the browser

ARCH.js gives browser applications a runtime layer for loading and using JavaScript packages directly in the browser. Bring more of the ecosystem into your frontend without treating the browser as the final step.

        <h3>{video.title}</h3>
        <p>{video.description}</p>
      </a>
      <LikeButton video={video} />
    </div>
  );
}

Packages running in the browser

Whether you're building a tiny experiment or a larger frontend, ARCH.js gives you a way to bring package-based capabilities closer to the browser itself.

Build with packages, not restrictions

ARCH.js is designed around the idea that browser projects should be able to reach further into the JavaScript ecosystem. Load packages, work with their exports, and keep building in the environment your users already have.

VideoList.js

function VideoList({ videos, emptyHeading }) {
  if (videos.length === 0) {
    return <h2>{emptyHeading}</h2>;
  }
  return (
    <div>
      <h2>My videos</h2>
      <ul>
        {videos.map(video =>
          <li key={video.id}>
            <Video video={video} />
          </li>
        )}
      </ul>
    </div>
  );
}

Add capabilities wherever you need them

A browser application can do more than render a page. ARCH.js can bring packages for OCR, rendering, data processing, and other tasks directly into client-side applications.

LikeButton.js

function LikeButton() {
  const [liked, setLiked] = useState(false);
  if (liked) {
    return 'You liked this';
  }
  return (
    <button onClick={() => {
      setLiked(true);
    }}>
      Like
    </button>
  );
}

Stay close to the web

ARCH.js works with the browser instead of trying to hide it. Keep using standard web APIs, JavaScript, and the platform underneath while adding a more capable package-loading environment.

Go beyond a simple loader

ARCH.js is designed to grow into a browser-side runtime layer. Packages can be resolved, loaded, cached, and exposed to your application through a consistent interface while the web remains the foundation.

The goal is simple: make the browser feel like a more capable JavaScript environment without making web development unfamiliar.

Explore ARCH.js

Build for the browser you have now

ARCH.js is an evolving project focused on making browser-side JavaScript more capable, modular, and practical. It is built around real applications and the capabilities already available on the web.

The project is still growing. New runtime APIs, package-loading capabilities, and compatibility layers can be added without changing the core idea: give the browser more to work with.
